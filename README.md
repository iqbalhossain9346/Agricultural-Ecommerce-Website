# E-commerce Based Agricultural Website with Interactive Surface

## Project Overview

This project was developed as my undergraduate final-year project for the Bachelor of Science in Computer Science and Engineering (CSE).

The project focuses on an agricultural e-commerce platform designed to connect agricultural producers and consumers through an online marketplace.

The website was developed using WordPress and PHP, with WooCommerce and Dokan supporting e-commerce and multi-vendor marketplace functionality.

## Technologies and Platforms

- WordPress
- PHP
- MySQL
- WooCommerce
- Dokan
- HTML5
- CSS3
- Bootstrap
- JavaScript

## Development Environment

- Operating Systems: Windows, Linux and macOS
- IDEs: Sublime Text and Notepad++

## Project Objectives

- Develop an online agricultural marketplace.
- Provide an online platform for agricultural products.
- Connect agricultural producers and consumers.
- Support e-commerce functionality.
- Provide a web-based marketplace environment.
